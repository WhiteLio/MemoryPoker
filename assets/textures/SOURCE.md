# Slate texture

Patterned Slate Tiles by Dimitrios Savva, from Poly Haven.

Source: https://polyhaven.com/a/patterned_slate_tiles

License: CC0, https://polyhaven.com/license

The game uses a cropped section of a single stone from the 4K diffuse JPEG. The crop is grayscale/colorized blue-gray and mirrored into a tile to avoid visible seams. The adapted bitmap is stone-wall.jpg. The original 1K reference is slate.jpg. No monitor-pixel or artificial grid texture is applied.
